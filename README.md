## Технические правила
- GitHub Pages: обновления из `main`. `.github/workflows/site.yml` запускает `python scripts/validate_site.py` и `node --check script.js`.
- На каждой странице уникальные метаданные, canonical, Open Graph, Schema.org, alt и внутренние ссылки; `sitemap.xml` содержит все 17 URL.
- Используются реальные фотографии и адаптивные WebP. **Существующие изображения не заменены**, доработки касались текстов, HTML и CSS.
- Визуальная система: Cormorant Garamond, Manrope, тёмно-зелёный, кремовый и медный. Mobile-first верстка с меню, контактными кнопками и сохранением доступности.
- Клики по телефону и Instagram могут передавать события в аналитическую систему, но **Яндекс Метрика не подключена без фактического ID счётчика**.
- При подключении домена следует обновить canonical, OG, sitemap и адреса JSON-LD.

## Что не считается подтверждённым
Наличие GitHub Pages и успешный CI не доказывают реальную скорость, SEO-позиции, рекламоотдачу, поведение гостей или наличие доступных дат. Результаты Lighthouse/Core Web Vitals и реальная конверсия не измерены. Для доказательства доверия нужны настоящие кадры работы мастера и подтверждённые отзывы с согласия гостей.

Текущий сайт не продаёт лечебные свойства и не утверждает универсальную безопасность банных процедур.
