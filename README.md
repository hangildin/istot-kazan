## Запуск на GitHub Pages без домена

1. Создать отдельный **публичный** репозиторий `istot-kazan` в аккаунте `hangildin`. Не создавать его внутри других проектов BIS и пр.
2. Загрузить в корень нового репозитория содержимое этого архива; `index.html` должен лежать в корне ветки `main`.
3. В **Settings → Pages → Source** выбрать **GitHub Actions**. Файл `.github/workflows/site.yml` проверит все 10 страниц и автоматически опубликует сайт при push в `main`.
4. После успешной публикации и проверки фактического URL (обычно для указанного аккаунта/имени репозитория это `https://hangildin.github.io/istot-kazan/`) выполнить:

   ```bash
   python activate_domain.py https://hangildin.github.io/istot-kazan
   ```

   Повторно отправить изменённые HTML/robots.txt/sitemap.xml в `main`. Так будут установлены корректные canonical и OG URL для временного адреса.
5. При покупке домена повторить шаг 4 с окончательным **реально подключённым** доменом и указать его в Pages Settings. Создать `CNAME` только после подтверждения домена.

> Указанный шаблон GitHub Pages URL не является подтверждённой рабочей ссылкой до публикации.

## Проверка

Локальные автоматические проверки:

```bash
python scripts/validate_site.py
```

Скрипт проверяет число заголовков H1, SEO-метаописания, alt, размеры изображений, локальные ссылки и якоря, JSON-LD, наличие телефона и Instagram, отсутствие форм. CSS протестирован в headless Chromium на основных ширинах 320, 360, 375, 390, 430, 600, 768, 820, 1024, 1280, 1440 px. В браузерном тесте подтверждены меню, диалог фотографий, отсутствие ошибок JavaScript и горизонтального переполнения. Это **не** замена проверке публичного сайта с интернетом, реальному Lighthouse или пользовательским конверсионным испытаниям.

В этом окружении **не запускался Codex**: отдельного инструмента Codex нет. В GitHub добавлена автоматическая проверка кода; после публикации возможен отдельный review через доступный Codex.

## Скорость / SEO

- Адаптивные размеры и форматы WebP; `srcset`, `sizes`, `lazy loading` для большинства фотографий, высокий приоритет для главного фото.
- Самодостаточные HTML/CSS/JS, без бэкенда и сбора персональных данных.
- На страницах уникальные title/description/H1, локальная разметка услуг и статей JSON-LD, внутренняя перелинковка, alt.
- `activate_domain.py` генерирует карту сайта и абсолютные SEO-адреса только по **реальному подтверждённому** адресу.
- Замеры реальных Core Web Vitals после публикации не проводились.
